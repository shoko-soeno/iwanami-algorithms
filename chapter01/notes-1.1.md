# 1.1 アルゴリズムの正しさ — 復習問題1.1から学べること

輪読会用の自分のまとめ。本文の引用ではなく、読んだ内容を自分の言葉で整理したもの。

## 1. 「正しいアルゴリズム」の2つの条件

| | 条件 | 呼び方 |
|---|---|---|
| (1) | 答を出すなら、その答は必ず正しい | 部分正当性 (partial correctness) |
| (2) | どんな入力でも、必ず有限時間で止まる | 停止性 (termination) |

- 両方そろって初めて「正しい」と言える（全正当性, total correctness）。
- (1)だけでは不十分。何も出力せずに永遠に回り続けるプログラムも(1)は満たしてしまう。
- 「どんな入力でも」は、問題の前提に合う入力に限る。互除法なら正の整数だけ考えればよく、前提外の入力（0、負の数、実数）は事前のチェックで除く。

## 2. 正しさの証明は2つに分けて行う

### (1) 正しさ → ループ不変条件

- **表明 (assertion)**: プログラムのある地点で、変数の間に必ず成り立つ条件式。
- **ループ不変条件 (loop invariant)**: ループの各回の同じ地点で、毎回成り立つ表明。
- 証明の手順は数学的帰納法と同じ形。
  1. ループに入る直前に成り立つ（帰納法の基底）
  2. 成り立っている状態から1回まわしても、また成り立つ（帰納ステップ）
- ループを抜けたときの「終了条件」と「不変条件」を合わせると、答が正しいことが言える。

### (2) 停止性 → 減り続ける量を見つける

- ループ不変条件は「間違えない」ことしか保証しないので、止まることは別に示す。
- 定番の方法: **ループのたびに必ず減り、しかも下限がある量**を見つける。
  そうすれば繰り返し回数に上限がある。

## 3. 例1: Euclid の互除法

| 項目 | 内容 |
|---|---|
| 不変条件 | gcd(m, n) = gcd(m₀, n₀)（m₀, n₀ は最初の値） |
| 開始時 | m = m₀, n = n₀ なので自明 |
| 1回まわす | (m, n) → (n, r) としても gcd は変わらない（下記） |
| 終了時 | r = 0 → n が m を割り切る → gcd(m, n) = n |
| 停止性 | 新しい n は前の n で割った余りなので、必ず前より小さい。0 以上なので、いつか 0 になる |

### gcd(n, r) = gcd(m, n) になる理由

d = gcd(m, n)、m = d·m′、n = d·n′（m′ と n′ は互いに素）、m = u·n + r とおく。

1. **r も d の倍数**: r = m − u·n = d·(m′ − u·n′)。よって d は n と r の公約数。
2. **d より大きい公約数はない**: n′ と m′ − u·n′ は互いに素。
   - もし k が両方を割り切るなら、m′ = (m′ − u·n′) + u·n′ も k で割り切れる。
   - すると k は m′ と n′ の公約数になるので、k = 1 しかありえない。
   - つまり「n′ の倍数を引いても、n′ との共通の約数は増えない」。

1 と 2 から gcd(n, r) = d × 1 = d。

#### 数値例（m = 48, n = 18）

| d | m′ | n′ | u | r | m′ − u·n′ |
|---|---|---|---|---|---|
| 6 | 8 | 3 | 2 | 12 = 6 × 2 | 2（3 と 2 は互いに素） |

## 4. 例2: 階乗（for 文を while 文に分解した形）

```c
v = 1; i = 1;
while (i <= x) { v = v * i; i = i + 1; }
```

| 項目 | 内容 |
|---|---|
| 不変条件 | ループ先頭で v = (i − 1)! |
| 開始時 | i = 1 のとき v = 1 = 0! |
| 1回まわす | v·i = (i − 1)!·i = i!、そのあと i を 1 増やすと再び v = (i − 1)! |
| 終了時 | i = x + 1 で抜けるので v = x! |
| 停止性 | x − i + 1 が毎回 1 ずつ減り、0 で止まる（ちょうど x 回） |

## 5. 輪読会で話したいこと

- **止まることと、速く止まることは別の問題。** 本文の停止性の議論では、ループ回数の上限を最初の n としていた。実際の互除法は桁数に比例する程度の回数（O(log n)）で終わる（例: gcd(1071, 1029) は3回）。どれだけ速いかは次の 1.2「計算量」のテーマ。
- **書き方によって扱える入力が変わる。** goto版と repeat版は最初に `m % n` を計算するので n = 0 で落ちるが、再帰版は先に n = 0 を判定するので gcd(m, 0) = m を返せる（`gcd.c` 参照）。
- **ループ不変条件は、証明だけでなく設計にも使える。** 「ループの各回で何が成り立っていてほしいか」を先に決めると、ループの中身が自然に決まる。

## コード

- `gcd.c` — 互除法の3つの書き方（goto / repeat / 再帰）
- `invariant.c` — ループ不変条件を `assert` で毎回チェックする実験版（互除法・階乗）

```sh
make run        # gcd
make check      # invariant
```

`assert` によるチェックは、いくつかの入力で不変条件が成り立つことを確かめているだけで、証明の代わりにはならない。証明は上の議論で行う。
